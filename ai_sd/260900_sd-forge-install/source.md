---
title: 【Stable Diffusion WebUI Forge】ローカルへのインストール方法（初心者向け）
---

Stable Diffusion Web Forge を、ローカルにインストールする方法を、インストール後の運用等も踏まえて纏めました。あまり予備知識なしに、まずはインストールしてみよう！といった方にお役に立てられるような内容にできたら幸いです。

●Stable Diffusion WebForge とは

元々は、ローカルで画像生成ができるStable Diffusion というAIソフトウェアがあり、その改良版です。Stable Diffusion の派生ソフトはいくつかあるのですが、Stable Diffusion WebForge（以下WebForge）はその中でも「軽くて速い」のが特徴です。

Stable Diffusionにまつわる用語は幾つかあり、紛らわしいので整理しておくと、、・Stable Diffusion：画像を生成する仕組みそのもの（モデル）。無料で公開されています。ただしこれ単体では、プログラミングの知識がないと使えません。・WebUI：Stable Diffusion をブラウザ上で、ボタンや入力欄等のUIから操作できるようにしたソフトウェア。・AUTOMATIC1111：その WebUI の中で最も広く使われているものです。開発者のアカウント名がそのままソフト名になっています。・Stable Diffusion WebForge：上記 AUTOMATIC1111 をベースに、VRAM容量が少ないマシンでも使える様に、処理を「軽く速く」したもの。といった関係になります。

速くなる度合いは GPU によって変わりますが、VRAM に余裕がない環境ほど効果が大きいのがポイントです。公式の数値では、VRAM 8GB で30〜45%の高速化。逆にハイエンドGPUでは数%程度で、あまり差は出ません。

つまり「ハイエンドではないGPUでも Stable Diffusion を動かしたい」という場合に、有力な選択肢になります。ベースになっている AUTOMATIC1111 の方は現在ほとんど更新が止まっている状況なので、これから始めるのであれば WebForge を選ぶのが現実的です。

●システム要件（Windows）

・OS：Windows 10 / 11（64bit）・GPU：NVIDIA製。VRAM 8GB 以上を推奨（4〜6GBでも動きますが、できることが限られます）＊RTX 50シリーズは別の手順が必要なため、この記事では対象外となります。・メモリ：16GB 以上・ストレージ：空き 100GB 以上を推奨

＊ストレージに関して：プログラム本体は10GB程度ですが、画像を生成するための「モデル」が1つ2〜7GBあり、使っている内にこれがどんどん増えていきます。インストール時にそれを考慮してディレクトリ構成を作っておいた方が良いです。（下記「ディレクトリを作る」で具体的に説明します）

●必要なプログラム

WebForge は、実はそれだけではインストールや実行ができません。WebForge を使用するには、以下の2つのプログラムが必要になります。

・python とは

Stable Diffusion も WebForge も、Python という言語で書かれたプログラムです。Python はそれを動かすための土台で、これがシステムにインストールされていないと、Python で書かれた WebForge も動きません。（Python は、AIプログラムを作る際に一般的に使用されているプログラム言語でもあります）注意点は、新しいバージョンを入れれば良いわけではないこと。WebForge は3.10系を前提に作られているので、3.11 や 3.12 だとインストールの途中でエラーになります。ここはバージョンを合わせてください。

・git とは

元々は、アプリケーション開発等のプロジェクトを共同作業する際に、作業内容や履歴を複数人で管理・共有して、開発を円滑に進める為のプラットフォームですが、完成したプログラムやプロジェクトを不特定多数に配布したりする際にも使われます。

＊プログラムは、「リポジトリ」と呼ばれる、GitHub のサーバ領域にアップロードされて、共有されます。プロジェクトの作業者は、その「リポジトリ」から、自分のローカルマシンにプログラムを取り込み、更新・追加してまた「リポジトリ」に戻す、といった形で共同作業を進めていきます。

今回は、GitHub 上の、WebForge のプログラムがある「リポジトリ」から、ローカルにクローン（ダウンロード）して取り込む為に必要となります。

＊python, git のインストールについて：実は「インストール方法1」のzip パッケージには python と git が同梱されているので、zipで WebForge をインストールするならば、これらの事前インストールは必須ではありません。ただし「インストール方法2」でリポジトリからインストールする場合には必要ですし、今後の運用等も踏まえて、ここではpython, git のインストールをする前提で説明しています。

●ディレクトリを作る

・インストール後の運用を踏まえてAIプログラムやデータ用のディレクトリを作成

インストールの前に、プログラムのインストール先、ディレクトリ構成を先に作っておきます。今後の運用も踏まえ、以下の様な構成を前提にしてインストールを進めていきます。

D:\AI
│
├─ apps
│   ├─ webui-forge
│   ├─ kohya_ss
│   └─ comfyui
│
├─ models
│   ├─ checkpoints
│   ├─ Lora
│   ├─ VAE
│   ├─ embeddings
│   └─ controlnet
│
├─ dataset
│   ├─ train
│   └─ raw
│
├─ output
│   ├─ images
│   └─ training
│
└─ tools

・ディレクトリ構成のポイント

ポイントとしては、Stable Diffusion や、kohya_ss 等の、AIプログラム群は一つのディレクトリ（apps）に纏めて管理し、その他モデルデータや出力データは、それぞれディレクトリを分けて管理していく、という事です。こうする事で、モデルデータを複数のAIアプリで共有して容量を節約したり、出力データがアプリ内に蓄積していったりする事を避け、バックアップや管理をしていく事ができます。特にモデルデータは一般的に重いので、ストレージを効率的に使う為にも、複数のAIアプリで共有して使える様にしておいた方が良いです。

＊ここでは、ひとまず大まかにディレクトリだけ作っておいて、具体的にそのディレクトリを指定するのは、WebForge をインストールした後に行います。

●必要なプログラムの確認

・python やgit はインストールしてたっけ、、？という場合

WebForge をインストールする前に、事前に必要なプログラムをインストールしますが、場合によっては、既にインストールされている場合もあるかと思うので、「入れてたっけ、、？」という場合は以下の方法で確認しましょう。

＊python がインストールされているかを調べる

ターミナル（コマンドプロンプト）を開き▼以下を入力

python --version

▼出力結果

Python 3.10.x

等と、バージョン名が表示されれば、python がインストールされています。されなければ、新たにインストールします。

＊python 3.10 がインストールされているか調べる

python が既にインストールされていても、バージョンが合っていなければ動かないので、python が入っている事は分かっていても、バージョンは？という人は、バージョンを調べてみましょう。

ターミナル（コマンドプロンプト）▼以下を入力

py --list

インストールされているバージョンがリストアップされます。ver 3.10.x がインストールされていなければ、インストールします。

＊gitがインストールされているか調べる

ターミナル（コマンドプロンプト）を開き▼以下を入力

git --version

▼出力結果

git version 2.41.0.windows.1

この様にインストールされているgit のバージョンが表示されれば、インストール済み。表示されなければ、新たにインストールします。

＊git のバージョンは、お使いのコンピュータで使えるものであれば、特に何でも良いです。

1：python のインストール

インストールするバージョンは、Python 3.10.x で良いですが、3.10.6～3.10.9 あたりが安定している様です。＊ここでは、安定していて出来るだけバージョンの新しい3.10.9 のインストールを例に進めます。＊WebForge のgit リポジトリの説明では3.10.6 推奨と書いてあるので、そちらでも構いません。

・[Python 3.10.9 ダウンロードページ](https://www.python.org/downloads/release/python-3109/)

ページの下の方にある「Files」のセクションで、自分の環境にあったものをDLします。

※ここでは、Windows PC にインストールするので、「Windows installer (64-bit)」を選択します。

①インストーラーの起動

ダウンロードしたexe ファイルをダブルクリックして、インストーラーを起動します。

※任意の場所にexe ファイルを保存して起動

②インストール

※必要事項をチェックして「Install Now」からインストール開始

＊チェック項目
☑ Add Python to PATH
・環境変数にpython へのパスを通します。
・複数バージョンのpython をインストールして管理している場合は入れなくても良いです。

※インストール完了の表示がでたらウィンドウを閉じて終了

③インストール確認

ターミナル（コマンドプロンプト）▼以下を入力

python --version

▼出力結果

Python 3.10.9

この様にpython のバージョンが表示されれば、インストール成功です。

2：git のインストール

git は、使えればバージョンは何でも良いかと思います。

・[Git ダウンロードページ](https://gitforwindows.org/)

①インストーラーの起動

ダウンロードしたexe ファイルをダブルクリックして、インストーラーを起動します。

※任意の場所にexe ファイルを保存して起動

②インストール

※「Next」から手順に従ってインストール

python よりはインストールにかかるステップが多いですが、基本「Next」で進めてインストールします。

※進めていって「Next」が「Install」に変わったら、インストール開始になります。

※インストール完了の表示がでたらウィンドウを閉じて終了

③インストール確認

ターミナル（コマンドプロンプト）▼以下を入力

git --version

▼出力結果

・git version 2.41.0.windows.1

git のバージョンが表示されれば、インストール成功です。

3：stable-diffusion-webui-forge のインストール

下準備としての、git とpython のインストールができたので、本命のstable diffusion Forge のインストールを行っていきます。方法は2つあります。

まずは、以下のgitのURLにアクセスします。

・[stable-diffusion-webui-forge ダウンロードページ](https://github.com/lllyasviel/stable-diffusion-webui-forge)

●インストール方法1：zip ファイルをダウンロードしてインストールする場合

リポジトリページの下の方、「Installing Forge」の項目内にある、

※リンクをクリックでzip ファイルをDL。

[>>> Click Here to Download One-Click Package (CUDA 12.1 + Pytorch 2.3.1) <<<](https://github.com/lllyasviel/stable-diffusion-webui-forge/releases/download/latest/webui_forge_cu121_torch231.7z)

を先ほど準備しておいたAIアプリ構成ディレクトリの、「apps」内にDLします。

・DLしたファイルの解凍

webui_forge_cu121_torch231.7z

を解凍して、展開します。

●インストール方法2：git でリポジトリをクローンする場合

リポジトリページの「Code」ボタンから、HTTPSのリンクをコピーし、git clone で、先ほど準備しておいたAIアプリ構成ディレクトリの、「apps」内にリポジトリをクローンします。

※URLをコピーしてクローン。

インストールできたら、以下のステップで、セットアップを行います。

①update の実行

展開した

webui_forge_cu121_torch231

フォルダ内にある

update.bat

をクリックして起動。

※インストールされたフォルダ内の update.bat

プロンプトが立ち上がり、DLが進むので、暫く待ちます。無事終了し、プロンプトの最後に、

、、、、何かキーを押してください。

とうながされたら、enter を押して終了（ターミナルが終了）

②WebForge の実行

同じくwebui_forge_cu121_torch231フォルダ内にある

run.bat

をダブルクリックして起動します。

※インストールされたフォルダ内の run.bat

無事ブラウザでWebForge の画面が立ち上がったら成功！おめでとうございます。
